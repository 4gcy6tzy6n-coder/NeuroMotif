# Superseded reliability-shift sensitivity archive

This post-result sensitivity run used the initial arithmetic-mean no-gate control. Forward and reversal modes have unequal stationary occupancy, so its no-gate controller also changed average sensory gain and did not isolate removal of state dependence. The run is retained for history only and must not be used as the primary sensitivity result.

The corrected sensitivity analysis uses an occupancy-weighted gain and is published separately under `M2_RELIABILITY_SHIFT_V1`. Both the corrected result and the control-correction record state that the revision followed inspection of initial outputs, so it remains exploratory. The original v0 executable was not preserved; this data-only history package makes that reproducibility gap explicit.
