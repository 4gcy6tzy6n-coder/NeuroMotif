# Phase 2 — evidence-to-observable matrix

**Status:** current-record synthesis; no outcomes were recalculated and no new experiment is proposed or run. This matrix applies the provisional seven-concept glossary to evidence already documented in the project.

## Admission standard

A concept is eligible for an *interpretable cross-system computation* only if the candidate systems expose compatible abstract source/target roles, a named measurable quantity, identity and independent-unit provenance, and evidence that distinguishes structural possibility from functional use. For causal wording, intervention evidence must address that operation. “Both systems have a graph” is insufficient.

Legend: **YES** = documented observable at the stated granularity; **PARTIAL** = some required layers exist but a material boundary remains; **NO** = the current record lacks a required layer; **N/A** = not a relevant evidence stream.

## What is and is not computable now

**Computable descriptively from existing artifacts:** several graph statistics on the Fish1.5 explicit crosswalk subgraphs; published cell-class pathway/adjacency summaries for the worm; projection-level maps for R20. These are not new confirmatory tests and do not establish a functional motif.

**Not jointly identifiable from current records:** a cross-species effect with a common independent unit; animal-level worm E4 contrasts; a synapse-resolved R20 feedback motif; or a shared local structure→temporal-dynamics estimand replicated across two systems.

**Already tested and not to be reframed as positive:** Fish1.5 recurrence versus post-offset persistence. Its primary positive association was not supported and its frozen topology-null family was invalid. New predictors on the same exposed endpoint would be post-result exploratory and cannot repair this result.


This is not a claim that the concepts do not exist biologically. It says the current project records cannot support a common, independently interpretable cross-system computation. The C. elegans line does support a bounded published cell-class feedback result, but it cannot currently validate the Fish1.5 statistic; R20-01 demonstrates a coarser evidence-resolution boundary.

## Project consequence and next work package

The positive project arc—discover a recurrence/persistence motif in Fish1.5, triangulate it in other species, then encode that motif in a liquid network—is **not supported by the current evidence**. Do not build an LNN from a motif that the primary Fish1.5 association did not support. The remaining scientifically coherent route is to decide whether the project will be reframed around a bounded negative/inconclusive evidence-boundary contribution, or whether the owner wants a genuinely new independent biological question. The evidence does not justify choosing another Fish1.5 metric after seeing the current results.
